  [ageron/handson-mlp](https://github.com/ageron/handson-mlp). It is the answer key, not the textbook.
- **Kernel:** Python (HoARD)

## How to work through a chapter

1. Read the chapter in the book.
2. Copy the template and type the code yourself:

   ```sh
   mkdir notebooks/geron_handson_ml/ch03_classification
   cp notebooks/sample.ipynb notebooks/geron_handson_ml/ch03_classification/ch03.ipynb
   ```

3. Do the exercises before looking at any solution (30–60 minutes of real effort each, see `advice.md`).
4. Only then open `books/geron_handson_ml/` to compare: `books/` is hidden in VS Code, so set `"books": false` under
   `files.exclude` in `.vscode/settings.json`, and set it back to `true` when done.
5. Log what you missed in section 5 of your notebook.

Book updates (fixes for newer library versions): `make update-books`.
